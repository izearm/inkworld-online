# Ink World Online (รุ่นทดลอง 0.7.0)

ต่อยอดจาก Beta 0.5.4 (`codex/Beta test`) ในโฟลเดอร์ใหม่ `inkworld-online` · เกมออฟไลน์, Arena และ Editor ทำงานเหมือนเดิม

## เล่นในเครื่อง
```
npm install
npm run build
npm run server          → เปิด http://localhost:8787/ (2 เบราว์เซอร์/โหมดไม่ระบุตัวตน = 2 ผู้เล่น)
```
- มือถือในวง Wi-Fi เดียวกัน: `http://<IP เครื่อง>:8787/`
- ระหว่างแก้โค้ด: `npm run server` + `npm run dev` (Vite ส่งต่อ /api และ /ws ให้เซิร์ฟเวอร์เอง)
- บัญชีเก็บที่ `server-data/accounts.json` (ไม่มี DATABASE_URL)

## ขึ้น Render
1. อัปโฟลเดอร์นี้ขึ้น GitHub (ไม่ต้องมี node_modules / dist)
2. Render → New → **Blueprint** → เลือก repo → Render อ่าน `render.yaml` แล้วสร้างเว็บ + ฐานข้อมูล Postgres ให้
3. เปิด `https://<ชื่อ>.onrender.com/`
- แพ็กฟรี: เซิร์ฟเวอร์หลับเมื่อไม่มีคนใช้ ~15 นาที (เปิดครั้งแรกรอ ~30 วิ) · ฐานข้อมูลฟรีมีอายุจำกัด ตรวจเงื่อนไขในหน้า Render ก่อนใช้จริง

## เล่นบน GitHub (หน้าเกม) + Render (เซิร์ฟเวอร์)
GitHub Pages รันได้แค่ไฟล์หน้าเว็บ เซิร์ฟเวอร์ (บัญชี/ห้อง/เซฟ) จึงต้องอยู่บน Render
1. โค้ดอยู่บน GitHub แล้ว: `izearm/inkworld-online` branch `main` (มี `.github/workflows/pages.yml`)
2. Render → New → Blueprint → เลือก repo → กรอก `INVITE_CODES` (เช่น `INKTEST,FRIEND2026`) และ `ALLOWED_ORIGINS` = `https://<ชื่อ GitHub>.github.io`
3. GitHub repo → Settings → Pages → Source = **GitHub Actions**
4. Settings → Secrets and variables → Actions → **Variables** → `ONLINE_SERVER_URL` = `https://<ชื่อ>.onrender.com`
5. Actions → Deploy Pages → Run workflow (หรือ push ใหม่) → ลิงก์เล่น: `https://<ชื่อ GitHub>.github.io/<repo>/`
- เล่นตรงบน Render ก็ได้: `https://<ชื่อ>.onrender.com/`

## รหัสเชิญ (เฉพาะช่วงทดสอบ)
- ช่อง "รหัสเชิญผู้ทดสอบ" อยู่ในหน้าตั้งชื่อ (สมัครครั้งแรก) · เว้นว่าง = เริ่มเนื้อเรื่องปกติ
- ใส่ถูก = ตัวละครทดสอบ Lv50 จบเรื่องแล้ว อาวุธ+อุปกรณ์หายากครบชุด Lumi 3000 ยา 10 · เมืองออนไลน์รอวางบนแผนที่โลกทันที
- ตั้ง/เปลี่ยนรหัส: Render → Environment → `INVITE_CODES` (คั่นด้วย , ไม่สนตัวพิมพ์) · ลบรหัสออก = ปิดรับผู้ทดสอบใหม่ · ในเครื่อง: `INVITE_CODES=INKTEST npm run server`

## เส้นทางผู้เล่น (เข้าทางเดียว · ต้องออนไลน์เสมอ)
`index.html` → **ลานกระดาษขาว** มีต้นหมึกโบราณกลางลาน → เดินเข้าใกล้ต้นไม้ → ป๊อปอัป **เข้าเกม / เข้าชม (เร็วๆ นี้) / เร็วๆ นี้**
→ เข้าเกม → ID + รหัส (สมัครได้) → ตั้งชื่อ (ครั้งแรก) → เริ่มเนื้อเรื่องที่หมู่บ้าน หรือเล่นต่อจากเซฟบนบัญชี
→ จบ 7 ด่าน → **เมืองหมึกออนไลน์** เป็นหน้ากระดาษรอวางบนแผนที่โลก → ในเมือง: ประตูตะวันออก = ป่าเงาหมึก Co-op 2 คน Lv50 · ประตูตะวันตก = แผนที่โลก (กลับไปฟาร์มด่านเก่าได้)
- ลานต้นหมึก: เดินออกห่างเกิน 3.2 ช่องจอค่อยๆ มืด · เกิน 6.2 ช่องเดินต่อไม่ได้ · เดินกลับหาต้นไม้จอสว่างขึ้น
- ด่านเนื้อเรื่อง/ด่านเก่า = เล่นคนเดียว (ไม่เห็นใคร) · เห็นกันเฉพาะเมืองออนไลน์และดันเจี้ยน Co-op
- เซฟอยู่บนบัญชีอย่างเดียว (บันทึกทุก ~4 วิหลังเกมเซฟ + ตอนปิดแท็บ) · บันทึกไม่ได้ → เกมหยุดพร้อมแจ้ง "ขาดการเชื่อมต่อ" จนต่อได้
- เครื่องจำการล็อกอินไว้ · ออกจากระบบได้ที่ป๊อปอัปต้นไม้ · เซฟเก่าใน localStorage ไม่ถูกนำเข้า (ทุกคนเริ่มใหม่)
- `?preview=1` / `?cave=1` (จาก Editor) ยังเปิดแบบออฟไลน์เดิมโดยไม่ต้องล็อกอิน · `online.html` พากลับหน้าแรก

## ใครตัดสินอะไร
| เรื่อง | ผู้ตัดสิน |
|---|---|
| การเดิน | เครื่องเจ้าของตัว (ส่ง 10 ครั้ง/วิ) |
| AI / HP / ตาย / Alpha / ลำดับบอส | Host = คนแรกในห้องดันเจี้ยน (ส่ง snapshot 10 ครั้ง/วิ) |
| ดาเมจผู้เล่น → ศัตรู | คนตีคิดด้วยสเตตัสตัวเอง → Host หัก HP |
| ดาเมจศัตรู → ผู้เล่น | Host ตัดสินว่าโดน → ผู้โดนหักเกราะเองด้วย `hurtPlayer` เดิม |
| ของดรอป / EXP | แยกต่อคน: ทุกคนในห้องได้ EXP และสุ่มของของตัวเองเมื่อ Host ยืนยันศัตรูตาย |
| ตายในออนไลน์ | เสีย EXP ตามกติกาเดิม ไม่เสียของ เกิดใหม่ที่ทางเข้าทันที |

## หลุด / กลับเข้าห้อง
- เมือง: ค้าง 10 วิ แล้วหายไป · ดันเจี้ยน: ค้างแบบโปร่งแสง 30 วิ (ศัตรูไม่ตี) ต่อกลับทันจะอยู่ห้องเดิม เกินเวลาจะกลับไปเมือง
- Host หลุด → ผู้เล่นที่เหลือเป็น Host ทันทีจาก snapshot ล่าสุด · Host เดิมกลับมาเป็น Guest
- ล็อกอินซ้อนจากที่อื่น → เครื่องเก่าถูกออก

## เซฟ (เซิร์ฟเวอร์เป็นหลัก)
- ตอนเข้า: เทียบ `_savedAt` ในเครื่องกับบัญชี ใช้ฉบับใหม่กว่า · สำรองเซฟในเครื่องไว้ที่ `paperdungeon_inkworld_save_v1_backup_online` ทุกครั้ง
- ระหว่างเล่น: ใช้สำเนา · ซิงก์ทุก ~20 วิ, ตอนออก, ตอนปิดแท็บ
- เขียนกลับเฉพาะตัวละคร (เลเวล EXP สเตตัส สกิล อุปกรณ์ กระเป๋า ที่ฝาก Lumi Artifact HP/หมึก, ตัวนับ) **ไม่แตะ** เควส ดินแดน ตำแหน่ง ฉากจบ → เปิดเกมออฟไลน์ต่อได้ที่เดิม
- `save.ts` เพิ่มเพียง `_savedAt` ตอนเขียน (เซฟเก่าอ่านได้ตามปกติ)

## ข้อจำกัดของรุ่นทดลอง
- ไฟลุก/ช้า/แช่แข็งที่ Guest ใส่ศัตรูยังไม่ส่งไป Host (ดาเมจตรงส่งครบ)
- ยังไม่เห็นเอฟเฟกต์สกิลของอีกคน เห็นท่าฟัน/ร่าย การเดิน และตัวเลขดาเมจ
- ท่าฟาดหางบอสที่ตั้งเวลาไว้ อาจเล็งตำแหน่งเก่าของเป้าหมาย
- ดาเมจยังเชื่อเครื่องผู้เล่น (ยังไม่มีระบบกันโกง)
- ยังไม่ได้ทดสอบบนมือถือจริง
